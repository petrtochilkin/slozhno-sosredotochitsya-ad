# Сложно сосредоточиться

Адаптивная страница с дневной, неоновой и автоматической цветовой темой.

Репозиторий: https://github.com/petrtochilkin/slozhno-sosredotochitsya-ad

Использованы семантический HTML, CSS Grid, переменные, медиазапросы, локальные шрифты и изображения. Исходный переключатель тем сохраняет выбор пользователя.

Для просмотра откройте `index.html` в браузере или запустите локальный HTTP-сервер.
